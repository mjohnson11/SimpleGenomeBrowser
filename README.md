# SimpleGenomeBrowser

This is meant to be a super simple genome browser for small (microbial) genomes. The goal is to have it be super easily extensible with plain javascript. Maybe it will be useful to someone other than me, but we'll see!

This was originally a hand-coded project, but now has had significant inputs from Claude and Gemini.

- See [CUSTOM_TRACKS.md](CUSTOM_TRACKS.md) for a comprehensive architecture guide, pre-rendered buffer mechanics, and instructions for building custom tracks and data sources.
